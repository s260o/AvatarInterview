# オープンラボ（研究室公開）用デモの運用

オープンラボの来場者（他の大学生・後輩）は、11月の本実験の参加者になる可能性がある。
実験の仕掛けを事前に知った人が参加すると、評価不安や自己開示の測定が成り立たなくなる。
そのため、デモでは「アバターと声で話す体験」だけを見せ、実験の操作内容は見せない。

## 起動方法

```
Server\start_openlab.cmd      ← サーバー（オープンラボモード）
Server\start_tunnel.cmd       ← 外部公開を使う場合のみ（別のターミナルで）
```

- 通常の起動方法（`python -m uvicorn main:app ...`）では、これまでどおり実験モードで動く。
- 起動時に「オープンラボモードで起動」と表示されれば有効になっている。
- `OPEN_LAB_MODE` は `.env` に書かない。本番の日に戻し忘れるおそれがあるため。
- **オープンラボが終わったら、サーバーを止めて通常の方法で起動し直す。**

## 公開範囲

### 見せない（サーバー側で無効化・差し替え済み）

| 項目 | 理由 | デモでの扱い |
|---|---|---|
| 評価主体（AI／人）の操作 | 要因A。教示の内容を知ると操作が効かなくなる | 実験者ページ（`/experimenter`）と操作用 API を無効化（404） |
| 人条件（WoZ）の仕組み | 「人が声を当てている」と知ると、人条件の受け止め方が変わる | 評価者の音声中継（`/ws/voice/*`）を無効化 |
| 本番の質問（4セット＋予備） | 事前に回答を準備でき、不安・自己開示の測定に影響する | デモ専用の軽い話題に差し替え（最近ハマっていること／休日の過ごし方／行ってみたい場所） |
| 締めの「総合的に評価されます」 | 評価の顕在性も操作の一部 | 「デモはここまでです」に差し替え。評価・採点・合否には一切触れない |
| 面接の構成（7分×4回） | 当日の流れが予想できてしまう | デモは1回 180 秒（`OPEN_LAB_DURATION_SEC` で変更可） |
| 研究の目的・実験の内容 | 上記すべて | アバターは質問されても答えず「そのあたりは研究室のメンバーに聞いてみてください」とだけ返す（AI か人か、うなずきを変えられるか、などの質問も同様） |

### 見せてよい

- MR 空間で、実際の机に座ったアバターと声で会話する体験
- 音声認識 → 応答生成 → 音声合成の流れと、返答の速さ
- 口の動き・うなずき・視線・表情・まばたき（**High 相当の1つの設定のまま**。切り替えは見せない）

### サーバーでは制御できないこと（当日の担当者が守る）

- **非言語行動の切り替えを見せない。** 実験セッションを開始しなければアバターは High のまま動く。Low に切り替えたり、High と Low を比べて見せたりしない。
- **Unity エディタの画面を来場者に見せない。** エディタ上の「実験条件マネージャ」パネルには評価主体（AI／人）や教示文が表示される。Quest 用にビルドしたアプリで行うか、エディタを使う場合は `ExperimentConditionManager` の `Show Experimenter Panel` と `VrmExpressionApplier` の `Enable Test GUI` を OFF にする。
- **空間認識のデバッグ表示（色つきの球）は OFF にする**（`MRUKDebugVisualizer` の `Auto Show On Load`）。
- **ポスターや説明で、実験の要因（評価主体の教示・非言語の豊富／抑制）を話さない。** デモをサーバー側で隠しても、説明で話せば同じことになる。説明は「アバター面接官と練習できるシステムを作っています」程度にとどめる。

## 当日の操作

- 来場者は右コントローラーの **A ボタンを押している間** 話す。
- 180 秒を過ぎた次の発話で、アバターが締めの台詞を言って終了する。その後は録音できなくなる。
- 次の来場者に交代するときは、**左コントローラーの Y ボタン**で会話をリセットする（または `POST /api/reset`）。
- 固まった場合は、サーバーとアプリを再起動する（オープンラボモードでは実験者ページの「アバター復旧」は使えない）。

## 来場者のデータ

- 来場者は研究参加の同意をしていないため、**発話内容はログに残さない**（既定）。
  - サーバーのログでは発話が `<17文字・非記録>` のように伏せられる。
  - 会話ログは実験データと混ざらないよう `logs/openlab_YYYYMMDD.jsonl` に分けて保存し、時刻・処理時間・表情など発話以外の情報だけを残す。
- 来場者の音声は Gemini API に送られる（無料枠では Google の製品改善に使われる場合がある）。体験の前に口頭で伝える。

## 本実験への影響を避けるために

- サーバー側で隠しても、来場者が「アバター面接のデモを体験した」こと自体は残る。
- 本実験の募集時に「オープンラボで本研究のデモを体験した／説明を聞いた」かを確認し、扱い（除外するか、記録して分析で考慮するか）を指導教員と決めておく。
